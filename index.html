Desenvolver banco de dados

Habilitação Profissional Técnica em Informática · SENAC · 72 horas em 24 encontros. Você vai sair daqui com um banco de dados projetado, criado, povoado, consultado, protegido e documentado — o da Pizzaria Bella Massa, do requisito ao backup.

Como este site funciona

Todo comando aparece no terminal

O SQL vem dentro de uma sessão sqlcmd, com os prompts 1>, 2>, o GO no fim do lote e a saída real do SQL Server logo abaixo. O botão copiar leva só o comando, sem prompts e sem saída.

Um caso só, do início ao fim

Nada de tabela1 ou foo. Cada aula acrescenta uma peça ao modelo da pizzaria: cliente, telefone, endereço, pedido, item, produto, tamanho, entrega, pagamento, mesa e até o BINA que identifica quem está ligando.

Você marca o que já domina

Cada aula termina em checklist e quiz com comentário por alternativa. O progresso fica no seu navegador — nada é enviado a servidor nenhum, porque não existe servidor.

A trilha

Quatro módulos. O módulo 1, de modelagem, é o mais longo de propósito: modelo errado não se conserta com SQL bom.

O que será avaliado

Os cinco indicadores do plano de ensino da UC. Cada aula declara, no cabeçalho, quais deles ela atende.

Antes do primeiro encontro

Chegue na aula 01 com a máquina ligada e privilégio de administrador. Você vai instalar o SQL Server 2022 Express, o SSMS 20 e conferir a instalação com um SELECT @@VERSION no sqlcmd. Se a instalação local não for possível, a aula traz o caminho alternativo com Docker.
