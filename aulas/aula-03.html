Objetivos de aprendizagem

Ao fim desta aula você será capaz de:

  • Instalar o SQL Server 2022 Express em uma instância nomeada e identificar o que cada componente faz.
  • Configurar o modo de autenticação misto e habilitar o login sa com senha forte.
  • Habilitar o protocolo TCP/IP e confirmar que a instância responde na porta 1433.
  • Conectar na instância por três caminhos diferentes: sqlcmd, SSMS 20 e Azure Data Studio.
  • Validar a instalação com SELECT @@VERSION e interpretar edição, build e sistema operacional.

Problematização

As duas aulas anteriores foram inteiras no quadro: você já sabe o que é um SGBD, por que a planilha da Bella Massa não dá conta e como o modelo relacional organiza dado em relações. Nada disso vira software enquanto não existir um servidor de banco de dados rodando na sua máquina.

Esta é a primeira aula prática da unidade, e ela atende sozinha o indicador 2: instalar e configurar o SGBD conforme a necessidade do projeto. Ao fim dela você terá o SQL Server 2022 Express instalado, acessível pela rede e verificado por consulta — o chão sobre o qual as outras 21 aulas se apoiam.

As peças do ambiente

Cinco programas diferentes vão aparecer no seu menu iniciar, e é comum o aluno confundir um com o outro. Só o primeiro é o banco de dados; os outros são ferramentas que conversam com ele.

Componente O que é Você usa para
SQL Server 2022 Express O SGBD. Um serviço do Windows que fica rodando e guarda os dados. Nada diretamente — ele não tem tela.
SSMS 20 SQL Server Management Studio: a IDE oficial, instalada à parte. Escrever consultas, ver tabelas, gerar scripts, fazer backup.

Configuration Manager Painel de configuração de serviços e protocolos de rede. Ligar TCP/IP, mudar porta, reiniciar o serviço.
Instância

Uma instância é uma cópia independente do serviço do SQL Server na mesma máquina, com seus próprios bancos, logins e porta. A instalação Express cria por padrão a instância nomeada SQLEXPRESS, endereçada como NOME-DA-MAQUINA\SQLEXPRESS. Uma instância padrão (sem nome) seria endereçada só pelo nome da máquina. Guarde isso: metade dos erros de conexão do curso é gente digitando o endereço da instância errada.

Instalando o SQL Server 2022 Express

Baixe o instalador do SQL Server 2022 Express no site da Microsoft e execute como administrador. Ele pergunta o tipo de instalação logo na primeira tela.

  1. Escolha o tipo Custom

    Basic instala com tudo padrão e não pergunta a senha do sa, o que obriga você a corrigir depois. Download Media só baixa os arquivos. Escolha Custom: mais telas, menos retrabalho.

  2. Feature Selection: marque só o motor

    Marque Database Engine Services. Deixe de fora Machine Learning Services, PolyBase e Full-Text Search — nada disso é usado nas 72 horas e cada um acrescenta minutos de instalação e memória residente.

  3. Instance Configuration: mantenha SQLEXPRESS

    O nome padrão da instância nomeada é SQLEXPRESS. Mantenha. Todos os exemplos deste curso usam localhost\SQLEXPRESS; se você trocar, terá que traduzir cada comando.

  4. Server Configuration: Mixed Mode e senha do sa

    Marque Mixed Mode (SQL Server authentication and Windows authentication) e defina a senha do sa. Use algo forte de verdade — a política do Windows exige maiúscula, minúscula, dígito e símbolo. Nos exemplos do curso a senha é Bella@Massa2026.

  5. Collation: Latin1_General_CI_AS

    Na aba Collation, troque o padrão SQL_Latin1_General_CP1_CI_AS por Latin1_General_CI_AS. CI = case insensitive, AS = accent sensitive: "pizza" acha "Pizza", mas não confunde "acai" com "açaí". A aula 13 volta nesse assunto com calma.

  6. Instale o SSMS 20 depois, separadamente

    O SSMS não vem no instalador do motor desde 2016. É outro download, outro instalador, e ele pede reinício da máquina no fim.

Terminada a instalação, o serviço já deve estar rodando. Confirme pelo PowerShell antes de tentar qualquer conexão — se o serviço estiver parado, nenhuma ferramenta vai conectar e você vai perder tempo procurando o erro no lugar errado.

Se aparecer Stopped

Rode Start-Service -Name "MSSQL$SQLEXPRESS" em um PowerShell aberto como administrador. Se ele parar sozinho de novo depois do boot, o serviço está em Manual: mude para automático com Set-Service -Name "MSSQL$SQLEXPRESS" -StartupType Automatic.

Modo de autenticação e o login sa

O SQL Server aceita dois modos de autenticação. No Windows Authentication, quem entra é a sua conta do Windows e não existe senha separada. No Mixed Mode, além disso existem logins próprios do SQL Server, com senha guardada no banco master — é o que a aplicação Java da aula 23 vai usar, porque ela não roda com a sua conta de usuário.

TCP/IP, porta 1433 e SQL Server Browser

Na Express, o protocolo TCP/IP vem desabilitado. Enquanto você conecta da própria máquina, o SQL Server usa memória compartilhada e nada disso importa. No momento em que a aplicação Java, o Power BI ou o colega do lado tentarem conectar, a conexão falha. Ligue o TCP/IP agora, para não descobrir o problema na aula 23.

  1. Abra o SQL Server Configuration Manager

    Ele não aparece na busca do menu iniciar em algumas versões. Rode SQLServerManager16.msc na caixa Executar — o 16 é a versão interna do SQL Server 2022.

  2. SQL Server Network Configuration > Protocols for SQLEXPRESS

    Clique com o botão direito em TCP/IP e escolha Enable.

  3. Fixe a porta 1433

    Em Properties > IP Addresses, role até IPAll. Apague o conteúdo de TCP Dynamic Ports e escreva 1433 em TCP Port. Instância nomeada usa porta dinâmica por padrão, e porta que muda a cada reinício é porta que quebra string de conexão.

  4. Reinicie o serviço

    Em SQL Server Services, botão direito em SQL Server (SQLEXPRESS) > Restart. Configuração de rede só vale depois do reinício.

Conectado, você mesmo pode perguntar ao servidor por qual porta a sua sessão entrou. Este é o teste que vale mais que qualquer print de tela:

Para que serve o SQL Server Browser

Com porta dinâmica, o cliente que digita MAQUINA\SQLEXPRESS não sabe em qual porta bater. Quem responde isso é o serviço SQL Server Browser, na porta UDP 1434. Se você fixou a porta em 1433 e conecta sempre por host,1433, o Browser deixa de ser necessário. Se conecta pelo nome da instância, ele precisa estar rodando.

SSMS 20 e Azure Data Studio

O SSMS 20 mudou um padrão que pega todo mundo de surpresa: na janela de conexão, o campo Encryption agora vem como Mandatory. Como a sua instância local usa um certificado autoassinado, a conexão é recusada antes mesmo de checar a senha.

A correção em ambiente de estudo é marcar Trust server certificate na aba Connection Properties, ou trocar Encryption para Optional. Em produção a resposta é outra: instalar um certificado válido no servidor. No sqlcmd versão 18 ou superior, o equivalente é a flag -C, que aparece nos comandos desta aula.

Configurada a conexão, abra uma nova janela de consulta (Ctrl+N) e rode o mesmo teste. No SSMS não existem os prompts numerados: a janela é um editor, e o GO separa lotes:

O Azure Data Studio conecta na mesma instância, com o mesmo endereço, e é a alternativa quando a máquina é Linux ou macOS, ou quando o SSMS pesa demais. Ele não tem o gerador de diagramas nem o assistente de importação que a aula 22 usa — por isso o curso adota o SSMS como ferramenta principal e o ADS como apoio.

Erros comuns

Msg 18456 Login failed for user 'sa'

Acontece em três situações: senha errada, login sa desabilitado ou instância ainda em modo somente Windows. A mensagem é propositalmente vaga — o SQL Server não conta ao atacante qual das três é.

Correção: conecte com autenticação do Windows (-E), rode SELECT is_disabled FROM sys.server_principals WHERE name = 'sa'; e, se vier 1, execute ALTER LOGIN sa ENABLE; seguido de ALTER LOGIN sa WITH PASSWORD = '...';. Confira também o modo de autenticação com SERVERPROPERTY('IsIntegratedSecurityOnly').
Erro 53 Could not open a connection to SQL Server

O cliente nem chegou a falar com o motor. Ou o nome da instância está errado, ou o serviço está parado, ou o TCP/IP está desabilitado, ou o firewall bloqueou a porta.

No exemplo acima o erro é só uma letra: SQLEXPRES em vez de SQLEXPRESS.

Correção: confira o nome da instância no Configuration Manager, garanta que o serviço está Running, habilite o TCP/IP e libere a porta 1433 no firewall com New-NetFirewallRule -DisplayName "SQL Server" -Direction Inbound -Protocol TCP -LocalPort 1433 -Action Allow em PowerShell administrativo.
SSL Provider The certificate chain was issued by an authority that is not trusted

A pegadinha do SSMS 20 e do sqlcmd 18: os dois passaram a exigir conexão criptografada por padrão, e o certificado autoassinado da instância local não é confiável para o sistema.

Correção: acrescente -C ao sqlcmd ou marque Trust server certificate no SSMS. Entenda o que está aceitando: você está dizendo "confio neste certificado sem verificar quem o emitiu", o que é aceitável em máquina local de estudo e inaceitável em servidor de produção.
Shell The term 'sqlcmd' is not recognized

O motor foi instalado, mas as ferramentas de linha de comando não — ou não entraram no PATH. O instalador do motor não traz o sqlcmd desde a versão 2019.

Correção: instale o pacote Microsoft ODBC Driver + SQL Server Command Line Utilities, ou use o sqlcmd que vem com o SSMS em C:\Program Files\Microsoft SQL Server\Client SDK\ODBC\170\Tools\Binn\. Feche e reabra o PowerShell depois de instalar: o PATH só é relido em um terminal novo.
